# 家族向け自動化ツール集

家族の日常をサポートする自動化ツールをまとめたリポジトリです。

## ツール一覧

### 食事プランナー

毎週の献立と買い物リストを自動生成してLINEに送信します。

- GitHub Actions で毎週決まった曜日に自動実行
- 2人分の食材を分量つきでリストアップ
- カテゴリ別にまとめた買い物リストをLINEに送信

### 薬リマインダー

家族への薬の飲み忘れ防止通知をLINEに送信します。

- 毎日朝・夜の2回、自動でLINE通知
- 飲んだ確認ボタン付きのメッセージ
- YAML ファイルで薬の種類・タイミングを管理

### Dify LINE チャットボット

Dify で作成したチャットボットを LINE 上で利用できるようにする連携ツールです。

- LINEで送ったメッセージを Dify の Chat API に転送し、回答を返信
- LINEユーザーごとに会話の文脈（conversation_id）を保持
- Webhookサーバーをデプロイすれば、あとはLINEのWebhook URL登録だけで利用可能
